llm-sys studies how large language model architectures evolve and how to make them efficient: attention and sparsity, model structure, and the kernels and serving stacks that run them. We publish papers with code and write up the ideas here.

Code is on [GitHub](https://github.com/llm-sys). For questions about a post, write to the corresponding author listed on it, or to [fangtaosong@xiaohongshu.com](mailto:fangtaosong@xiaohongshu.com).
